# 🚧 React-Training

Ce projet de démonstration utilise **Vite**, **Typescript**, **TailwindCSS**, **React Router V6**, **Eslint** + **Prettier** et **PNPM**.

Je place mes _composants de démonstration_, mes _exercices d'entraînement_ et divers _éléments de développement web_ React sur des pages individuelles.
